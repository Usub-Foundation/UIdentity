UIdentity¶

Temporary documentation

This documentation is temporarily generated by AI and should be reviewed by the maintainers before it is treated as authoritative.

UIdentity is a C++23 Keycloak and OpenID Connect integration project. It provides reusable authentication building blocks and a small unet-based runtime for PKCE login, OAuth callback handling, cookie-based sessions, token refresh, logout, JWT validation, and multi-realm Keycloak deployments.

The project currently centers on:

  • PKCE authorization URL generation with one-time state storage.
  • OAuth authorization-code exchange and refresh-token handling.
  • Token revocation, introspection, and userinfo requests.
  • JWT access-token validation against Keycloak JWKS.
  • JWKS caching for repeated validations.
  • Bearer-token middleware that attaches a RequestContext to unet requests.
  • Redis-backed and in-memory state storage.
  • A runtime server with login, callback, logout, /me, liveness, readiness, and startup endpoints.

Project Layout¶
